# 참여형 최애 지도 서비스 요구사항

사용자와 검토한 기능적·비기능적 요구사항이다. 초기의 추천·좋아요·댓글과 숨김·복구 기능은 최종 결정에 따라 제외했다. 기술 선택·구현은 이번 단계에서 다루지 않는다.

## 1. 목적과 운영 방향

- 완성차 IT 센터 CA 활동에서 동료들의 최애 장소·산책코스를 함께 지도에 모은다.
- 핵심 성공 기준은 **즐거운 현장 참여 경험**이며, 현장 피드백으로 확인한다.
- 삼성역 인근을 기본 탐색 지역으로 하되 다른 지역의 등록도 허용한다.
- 행사 이후에도 계속 참여할 수 있다.
- 첫 배포 이후 별도 v2 없이 사용자 피드백에 따라 개선한다. 의견은 부스 운영자가 직접 받는다.

## 2. 접속과 참여자 정보

- QR 또는 웹 주소로 접속하며, 주소를 아는 누구나 이용할 수 있다.
- 로그인 없이 지도·랭킹을 바로 열람한다.
- `최애 등록하기`·`나도 최애로 등록` 클릭 시 브라우저의 참여 정보가 없으면 닉네임·사전 등록된 팀 입력 모달을 표시한다. 저장 후 누른 등록 흐름을 이어가고, 취소·Esc·배경 클릭은 원래 화면을 유지한다. 페이지 열람만으로 모달을 표시하지 않는다. ‘기타’ 팀은 제공하지 않는다.
- 참여 정보 없음·조회 중·만료·조회 실패 상태에서는 본인 등록 관리/수정 UI를 표시하지 않는다. 유효한 자격으로 확인된 참여자의 등록에만 표시한다.
- 닉네임 중복은 허용하며, 수정하면 기존 등록에도 반영한다.
- 팀은 참여자가 변경할 수 없고, 운영자가 정정하면 기존 등록과 집계에 반영한다.
- 동일인 구분은 같은 기기·브라우저 수준으로 한다. 다른 기기나 사용 기록 삭제를 통한 재참여 가능성은 허용한다.

## 3. 최애 등록과 관리

- 새 장소·코스를 등록하거나 기존 항목을 **‘나도 최애로 등록’**할 수 있다.
- 등록마다 문구 **1~100자 필수**, 사진 **최대 3장 선택**이다.
- 등록 완료 후 해당 장소·코스 상세로 이동해 자신의 문구·사진과 증가한 등록 횟수를 확인한다.
- 한 사람은 같은 장소·코스를 카테고리와 관계없이 한 번만 등록한다. 서로 다른 항목의 등록 개수는 제한하지 않는다.
- 닉네임·팀·문구·사진은 누구나 볼 수 있다.
- ‘내 최애’에서 자신의 등록을 모아보고 문구·사진·카테고리를 수정하거나 등록을 삭제한다.
- 별도 추천·좋아요·댓글 기능은 없다.

## 4. 장소·산책코스·카테고리

- 장소는 검색 결과나 지도에 표시된 실제 장소를 선택한다. 임의 위치·장소명으로 직접 등록하지 않는다.
- 산책코스는 **이름과 이동 경로가 필수**다. 거리·예상 시간은 지도 서비스에서 제공 가능하면 표시한다.
- 기존 코스를 선택하면 등록 횟수를 합산한다. 따로 만든 유사 코스는 별개로 취급한다.
- 코스 작성자가 자신의 최애 등록을 삭제해도 다른 사람의 등록이 있으면 코스를 유지한다.
- 공유 코스의 이름·경로 정정은 운영자만 할 수 있다.
- 초기 카테고리는 맛집·카페·산책코스이며, 관리자는 장소형·경로형 카테고리를 추가할 수 있다.
- 같은 장소도 등록자마다 다른 카테고리를 선택할 수 있다.

## 5. 지도와 랭킹

- 순위는 **현재 남아 있는 최애 등록 횟수의 전체 기간 누적**으로 정한다.
- 동점은 공동 순위로 표시한다. 예: 1위·1위·3위.
- 전체 랭킹은 전체·맛집·카페·산책코스·커스텀 탭으로 조회한다. 전체는 모든 팀·카테고리, 맛집/카페/산책코스는 모든 팀의 해당 카테고리를 집계한다. 커스텀 탭 내부에서만 팀·카테고리를 조합하며 기본은 내 팀·전체 카테고리, 내 팀 정보가 없거나 자격이 만료됐으면 전체 팀이다. 팀 조건은 해당 팀 구성원이 등록한 장소·코스의 순위이며 팀 자체의 순위가 아니다.
- 랭킹 탭·커스텀 조건과 지도 핀은 함께 바뀐다. 홈 요약·롤링 랭킹과 부스 화면은 기존 동작을 유지한다.
- 지도에는 선택 조건에 해당하는 항목만 표시하고, 횟수에도 같은 조건을 적용한다.
- 장소 상세는 이름 바로 아래에 저장된 주소와 복사 아이콘 버튼을 제공한다. 주소가 없으면 주소 정보 없음으로 표시하고 복사 버튼은 제공하지 않는다. 코스는 기존 코스 안내·참고 거리를 유지한다.
- 장소·코스 상세에 모든 팀·카테고리의 장소·코스를 합친 전체 순위를 표시한다. 진입 탭·필터와 무관하며 공동 순위는 1·1·3 규칙이다. 전체1·2·3위는 이름 옆에 랭킹과 동일한 금·은·코랄 트로피를 표시하고, 등록0건이면 순위 없음으로 표시한다.
- 상세 화면의 문구·사진은 팀·카테고리 조건 없이 전체 등록을 표시한다. 탐색 필터는 메인 복귀용으로 유지한다.
- 삭제된 등록은 내용과 집계에서 제외한다. 등록이 0건이 된 항목은 공동 지도·랭킹에서도 제외한다.

## 6. 휴대폰과 부스 화면

| 구분 | 요구사항 |
| --- | --- |
| 휴대폰 | 전체 화면 지도, 플로팅 메뉴·필터·실시간 상위5개 세로 티커·등록 버튼, 상세는 필터 없는 전체 등록을 표시하며 모바일 높은 바텀시트/PC 왼쪽 패널 |
| 부스 전용 화면 | 전체 화면 지도 위 등록 장소 핀·분류별 랭킹·핀 필터·알림 플로팅 UI |
| 부스 알림 | 모든 최애 등록에 대해 닉네임·팀·장소를 상단에 순서대로 표시 |
| 부스 산책코스 | 시작점 핀을 표시하고 선택한 코스의 전체 경로만 노출 |

등록이 몰리면 알림은 순서대로 대기할 수 있지만, 지도·랭킹의 갱신은 알림 대기와 별개로 진행한다.

## 7. 운영자 기능

- 팀·카테고리 추가, 이름 변경, 신규 선택 중단
- 선택 중단된 팀·카테고리의 기존 등록과 조회·랭킹 유지
- 참여자의 팀 오입력 정정
- 공유 코스 이름·경로 정정
- 개별 최애 등록 또는 장소·코스 전체 삭제
- 전체 삭제 전 대상과 함께 삭제될 등록 수 확인
- 숨김·복구 기능은 제공하지 않음

## 8. 사용성·성능·실패 대응

- 참여 환경: 아이폰 Safari·안드로이드 Chrome
- 부스·운영 환경: PC Chrome
- 동시 접속 목표: **100명**
- 정상 네트워크에서 첫 지도·랭킹 표시 **3초**, 사진 없는 등록 완료 **2초** 목표
- 다른 화면의 지도·랭킹에는 등록 결과를 **5초 이내** 반영
- 처음 방문한 사람이 도움 없이 첫 장소 등록을 **2분 이내** 완료하는 것을 목표로 설정. 사진 첨부·코스 작성은 별도
- UI 내 문구는 친근한 말투로 작성한다. 버튼, 안내, 입력 도움말, 완료·오류 메시지에도 일관되게 적용한다.
- 애니메이션은 등록 완료·지도 표시·순위 변화 중심으로 적용하고, 조작을 지연시키지 않으며 ‘동작 줄이기’ 설정 지원
- 그라데이션을 활용한 표현은 제외
- 등록 실패 시 문구·사진을 유지하고 재시도 지원. 반복 제출로 중복 등록되지 않도록 처리
- 연결 끊김 시 마지막 지도·랭킹과 갱신 중단 안내 표시. 재연결 시 최신 상태로 갱신
- 오프라인 등록 완료 기능은 제공하지 않음

## 9. 출시 전 운영 입력

- **산책코스 작성 방식:** 카카오 지도에서 점을 순서대로 추가하는 직접 경로 작성으로 확정했다. 자동 도보 길찾기는 제공하지 않는다.
- **행사 조건:** 행사일·운영 시간·전체 인원·팀 수·현장 네트워크·화면 준비 여부
- **사전 참여:** 제품 배포 후 바로 등록을 받고 행사 전후 같은 데이터를 유지한다.

행사일·실제 팀/관리자 목록·현장 네트워크·화면 준비는 출시 점검에 필요한 운영 입력이다. 미확정 제품 정책과 구분한다. 기술 설계는 [설계 목차](3-architecture/README.md)를 따른다.

## 10. 운영비 제약

2026-10-13 비용 질문에 대한 사용자 답변을 반영한다.

- 월 운영비는 **0원**, 유료 서비스는 사용하지 않는다.
- 기존 유료 계정·서버 없이 새로 구성한다.
- 사용자는 이 서비스를 **개인 프로젝트로 운영**하며, 프론트엔드 배포처는 **Vercel Hobby**로 선택했다. CA 행사에서 함께 사용하는 참여 목적은 유지한다.
- 사용은 행사에 집중되고 이후에는 가끔 참여한다. 행사 종료 후 참여 기능을 닫는다는 뜻은 아니다.
- 무료 DB가 휴면하면 운영자가 수동 재개하는 방식을 허용한다. 재개 전에는 정적 앱이 열려도 조회·등록이 일시적으로 불가능할 수 있다.
- 기술 구성·무료 한도·실패 대응의 설계 기본안은 [세부 설계](3-architecture/README.md)에 기록한다. 사용량·성능·실제 행사 조건은 구현 후 검증한다.

## 11. 확정한 세부 정책 (2026-10-13)

사용자의 항목별 선택과 나머지 기본안 채택을 반영한다. 아래는 구현 기준이며 테스트 통과 기록이 아니다.

| 항목 | 확정 기준 |
| --- | --- |
| 경로 입력 | 이름 1~50자, 서로 다른 점 최소2개·최대200개. 중심점 추가·마지막 점 취소·완료. 참고 선 거리만 표시 |
| 문자 입력 | trim 후 사용자에게 보이는 문자 단위(grapheme). 문구1~100자, 닉네임1~20자, 팀/카테고리명1~30자. 공백만 입력 불가 |
| 사진 | JPEG/PNG/WebP 원본 최대10MiB·40MP. 디코딩 불가 HEIC는 변환 안내. 긴 변1280px·512KiB 이하 JPEG로 저장하고 원본 미보관. 최대3장 |
| 사진 부족/실패 | 개별 재시도·제거 가능. 실패 사진을 몰래 제외하고 성공시키지 않음. 무료 용량 부족이면 사진 제거 후 명시적 제출 가능 |
| 초안 | 현재 작성 화면의 실패·재시도 동안 유지. 내부 이탈은 폐기 확인, 새로고침/브라우저 종료 후 복구 없음. 참여 정보 모달 저장 전 취소는 프로필 미생성. 저장 후 최애 작성 취소는 프로필 유지 |
| 조회 기본값 | 홈은 전체 팀·전체 카테고리, 모바일 상위5개 티커(4초·정지 가능)와 PC 상위5개. 전체 랭킹은5개 탭, 커스텀 최초 기본은 내 팀·전체 카테고리(내 팀 없음/만료는 전체 팀). 랭킹20건씩·동점 내부 대상 ID 순. 상세 최신순20건씩. 부스는 카테고리별 상위5건과 전체 보기, 핀 필터와 랭킹 표시 독립 |
| 수정 경합 | 현재 버전이 바뀌면 초안을 유지하고 최신 내용을 다시 확인. 전체 삭제 영향 변경도 재확인. 사라진 대상은 실패 안내·입력 유지·다른 대상 선택 |
| 삭제·재등록 | 개인 삭제도 사전 확인. 본인/관리자 삭제 후 새 등록 허용. 전체 삭제된 코스는 새 코스로 작성 가능하며 옛 ID 복구 없음 |
| 팀/분류 | 정규화한 이름은 팀 내/카테고리 유형 내 중복 금지. 신규 선택 재개 가능, 카테고리 유형 변경 불가. 중단된 팀의 기존 참여자는 추가 등록 가능. 중단된 분류를 유지한 문구·사진 수정 허용 |
| 관리자 | 사전 생성한 이메일/비밀번호 계정과 허용 목록. 세션 만료는 작업 거절·초안 유지·재로그인, 자동 재실행 없음 |
| 부스 알림 | 첫 방문 이후 등록부터4초/건. 같은 브라우저는 표시 완료 지점부터 이어서 재생. 현재 이름을 표시하고 삭제된 등록은 건너뜀. 순서는 서버 커밋 순서 |
| 자격 상실 | 브라우저 저장소 상실 시 자동 소유권 복구/닉네임 병합 없음. 공개 참여자 코드로 운영자 정정 대상을 구별하지만 그 코드로 소유권을 넘기지 않음 |
| 수동 백업 | 행사 직전·직후·DB 변경 전, 이후 변경이 있었던 주에 백업. 마지막 성공 백업 이후 데이터 손실 가능성을 수용 |
