## 첫 버전 구축

- [ ] 1. **목적 및 요구사항 정의**: 제공할 참여 경험, 대상, 필수 동작, 행사 운영 조건, 성공 기준을 정한다.
- [ ] 2. **첫 버전 범위 확정**: 첫 배포에 포함할 기능과 제외할 기능을 정하고, 포함 기능의 완료 기준을 세운다.
- [ ] 3. **화면·사용 흐름·데이터 설계**: 접속부터 참여·결과 확인까지의 흐름, 화면, 데이터와 기술 구성을 정한다.
- [ ] 4. **구현 및 검증**: 실행 환경을 준비하고 핵심 흐름을 구현한 뒤, 요구사항과 실제 사용 조건에 따라 검증한다.
- [ ] 5. **첫 배포 및 피드백 창구 마련**: 서비스를 배포하고 실제 접속·참여를 확인하며, 피드백 접수 방법을 마련한다.
