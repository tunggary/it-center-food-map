# 결정 기록

[전체 목차](../2-user-story.md)

2026-10-13 사용자 협의로 DEC-01~12의 제품 동작을 확정했다. 각 절의 질문은 결정 배경이며 아래 확정 결과가 현재 기준이다. 행사일·실제 명단·현장 환경은 출시 입력으로 구분한다. 관련 QA는 기대 결과를 갱신하고 실행 대기로 전환했으며 테스트 통과를 뜻하지 않는다.

## DEC-01

- **산책 경로 작성·정정:** 지도 서비스에서 가능한 입력 방법, 경유지·보행 경로 표현, 이름·경로 검증 방법, 제공되지 않는 거리·시간 표시.
- **확정된 경계:** 이름·경로 필수, 기존 코스 재등록은 합산, 유사 신규 코스는 별개, 공유 코스 정정은 관리자만 가능.
- **상태:** 확정 (2026-10-13).
- **결정:** 직접 점 추가·취소·완료, 이름1~50자·2~200점, 참고 거리만 표시. 자동 도보 길찾기·예상 시간 없음.

## DEC-02

- **행사 조건:** 일정·운영 시간·전체 인원·팀 수·실제 팀 목록·네트워크·부스 화면 준비·사전 참여 여부.
- **확정된 경계:** 동시 접속 목표 100명, 행사 종료 후에도 참여, 현장 재미를 피드백으로 확인.
- **상태:** 확정 (2026-10-13).
- **결정:** 제품 배포 후 즉시 등록 가능하며 행사 전후 같은 데이터를 사용한다. 행사일·명단·화면·현장 네트워크만 출시 입력으로 남긴다.

## DEC-03

- **랭킹·목록 표시:** 모바일 기본 랭킹 조건, 상위5개 플로팅 랭킹과 전체 패널의 선택·전환 방식, 최대 노출 건수, 동점 내부 순서, 상세 문구 정렬·더 보기, 부스의 카테고리별 랭킹 배치와 핀 필터 연동 여부.
- **확정된 경계:** 누적 등록 횟수, 공동 순위, 팀·카테고리 조합. 부스 핀 필터를 바꾼다고 다른 카테고리 랭킹까지 사라진다고 가정하지 않는다.
- **상태:** 확정 (2026-10-13).
- **결정:** 홈은 전체 팀·전체 카테고리 기본, 모바일 최상단 실시간 상위5개 세로 티커(4초 전환·일시정지)와 전체 패널. 전체 패널은 전체·맛집·카페·산책코스·커스텀 탭이며 커스텀 내부에서만 팀/카테고리를 선택한다. 커스텀 기본은 내 팀·전체 카테고리, 내 팀 없음/자격 만료는 전체 팀이다. 탭과 지도는 같은 조건이며 선택/페이지는 URL로 복원한다(2026-10-14 개편). 상세는 필터 없이 전체 등록 표시. 랭킹20건씩·동점 내부 ID순, 상세 최신순20건, 부스 분류별5건·전체 보기와 독립 핀 필터.

## DEC-04

- **입력 세부 규칙:** 공백만 있는 문구, 줄바꿈·이모지의 문자 수, 닉네임 길이·공백 처리, 사진 형식·용량·전송 실패 시 개별 상태.
- **확정된 경계:** 문구 1~100자, 사진 최대 3장 선택, 닉네임 중복 허용. QA의 ASCII 경계값은 현재 기준으로 바로 검증 가능하다.
- **상태:** 확정 (2026-10-13).
- **결정:** trim 후 grapheme 기준 문구1~100·닉네임1~20자. 사진 최대3장, 원본JPEG/PNG/WebP10MiB·40MP, 저장1280px·512KiB JPEG. 실패 사진은 개별 재시도/제거.

## DEC-05

- **이탈과 초기 실패:** 작성 중 취소·뒤로가기·새로고침 후 보존, 이탈 확인, 취소한 첫 참여 정보 유지, 목록 로딩 자체가 실패한 경우, 첫 접속부터 오프라인인 경우의 안내·재시도.
- **확정된 경계:** 현재 작성 화면에서 통신 실패하면 문구·사진을 유지한다. 기존 지도·랭킹이 있을 때 연결 중단은 마지막 결과를 유지한다.
- **상태:** 확정 (2026-10-13).
- **결정:** 현재 화면에서 실패/재시도 입력 유지. 내부 이탈은 폐기 확인. 새로고침/종료 복구 없음. 취소 프로필 미생성. 앱 최초 API 실패는 안내/재시도, 앱 자체 미로드 오프라인은 브라우저 오류.

## DEC-06

- **관리·수정 실패와 동시 변경:** 수정·삭제 실패 후 상태·재시도, 삭제 확인 이후 영향 등록 수가 달라진 경우, 작성 중 대상이 삭제된 경우, 열어 둔 상세에서 대상이 사라진 경우.
- **확정된 경계:** 전체 삭제 전 대상·영향 개수를 확인하며 취소는 데이터를 바꾸지 않는다. 성공하지 않은 작업을 성공으로 안내하지 않는다.
- **상태:** 확정 (2026-10-13).
- **결정:** 버전/전체삭제 영향 충돌은 최신 정보 재확인, 실패 시 초안 유지. 사라진 대상에 등록 완료하지 않고 다른 대상 선택을 제공한다.

## DEC-07

- **삭제 후 재참여:** 개인 삭제의 확인·취소 UX, 본인 삭제 후 같은 항목 재등록, 관리자 삭제 후 재등록, 전체 삭제된 코스의 재생성·접근 안내.
- **확정된 경계:** 삭제하면 공개 문구·사진·집계에서 제외하고 마지막 등록이 없어지면 공동 지도에서 제외한다. 숨김·복구 기능은 없다.
- **상태:** 확정 (2026-10-13).
- **결정:** 본인 삭제 사전 확인. 본인/관리자 삭제 모두 새 등록 허용, 새 알림 발생. 전체 삭제 코스는 새 ID로 작성하며 복구 없음.

## DEC-08

- **팀·카테고리 관리:** 목록 이름 검증·중복, 선택 재개, 카테고리 유형 변경 가능 여부, 중단된 팀의 기존 참여자가 추가 등록할 수 있는지, 작성 중 카테고리 선택이 중단됐을 때 처리.
- **확정된 경계:** 신규 선택 중단 후 기존 등록과 필터·랭킹은 유지한다. 참여자는 팀을 직접 변경할 수 없다.
- **상태:** 확정 (2026-10-13).
- **결정:** trim/NFC/소문자 정규화 이름1~30자·팀 내/분류 유형 내 중복 금지. 선택 재개 가능, 분류 유형 불변. 중단 팀 기존 참여 허용, 중단 분류 유지 편집 허용·신규 선택 거절.

## DEC-09

- **관리자 접근:** 관리 기능의 진입·인증 실패·세션 만료·권한 상실 시 사용자 흐름.
- **확정된 경계:** 일반 참여자의 무로그인 요구와 관리자 권한은 구분한다. 일반 참여자가 팀 정정·전체 삭제 등을 실행할 수 있다는 뜻이 아니다.
- **상태:** 확정 (2026-10-13).
- **결정:** 사전 생성한 이메일/비밀번호 Auth와 서버 allowlist. 만료/권한 회수는 거절, 초안 유지, 재로그인 후 명시적 재시도.

## DEC-10

- **부스 알림:** 한 건 노출 시간, 대기 한계, 재접속·새로고침 이후 지난 알림 재생 여부, 대기 중 닉네임 변경·등록 삭제 반영, 동시에 발생한 알림의 순서 판정.
- **확정된 경계:** 모든 최애 등록을 순서대로 알린다. 알림 대기 지연은 허용하지만 지도·랭킹 반영 5초 목표와 분리한다. 수정·삭제를 새로운 등록 알림으로 만들지 않는다.
- **상태:** 확정 (2026-10-13).
- **결정:** 첫 부스 이후 신규 등록부터4초씩, 같은 브라우저는 표시 완료 cursor 복구. 현재 이름 사용, 삭제 등록 제외, 커밋 순서. 미표시 대기는 DB 기록에 유지.

## DEC-11

- **참여 정보 상실:** 브라우저 기록 삭제나 기기 변경 이후 소유권·정정 요청 처리, 운영자가 동명 참여자의 요청을 구분하는 방법.
- **확정된 경계:** 닉네임·팀이 같다고 같은 사람으로 합치지 않는다. 다른 기기의 재참여를 엄격히 막지 않는다.
- **상태:** 확정 (2026-10-13).
- **결정:** 저장소 상실 후 자동 복구/동명 병합 없음. 공개 참여자 코드로 운영자 정정 대상 구별. 코드만으로 소유권 부여 금지, 삭제 요청은 운영자가 내용 확인 후 처리.

## DEC-12

- **측정 조건:** 정상 네트워크 수치, 캐시·지도 범위·데이터 양, 동시 접속자의 행동 비율, 반복 측정 횟수·합격 통계, 첫 사용자 테스트 인원·완료 비율.
- **확정된 경계:** 100명 동시 접속, 첫 지도·랭킹 3초, 사진 없는 등록 2초, 타 화면 반영 5초, 첫 장소 등록 2분. 수치는 임의 완화하지 않는다.
- **상태:** 확정 (2026-10-13).
- **결정:** 기존 데이터/네트워크/부하 조건 채택. 첫 표시3초·무사진2초는 각100표본 중95개 이상, 타 화면5초는 정상 표본 모두, 첫 사용자5명 모두2분. 상세는 검증 문서 기준.
