# 참여자 QA

[역할·화면·분기](../participant.md) · [공통 실행 규칙·테스트 데이터](../../2-user-story.md) · [결정 필요 사항](../decisions.md)

모든 실행 결과는 초기 상태다. 문서의 기대 결과는 실행 증거가 아니며, 실제 실행 전에는 통과로 바꾸지 않는다. 각 항목의 역할은 연결된 스토리를 따른다. 모든 항목에 공통 실행 기록 양식을 사용한다.

## QA-P-01-01

**QR·주소 최초 접속**

- 연결: [US-P-01](../participant.md#us-p-01) / SC-P-01 / BR-P-01-01.
- 준비: 참여 정보 없는 브라우저; 등록 데이터 존재
- 절차: QR을 열고 첫 화면을 확인한다. 같은 주소를 직접 열어 비교한다.
- 기대 결과: 로그인·닉네임 입력 강제 없이 지도를 볼 수 있다. 지도 중심, 한 줄 랭킹 헤더, 하단 등록 버튼이 보인다. 삼성역 인근을 기본 표시한다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-P-01-03

**지도 결과 없음**

- 연결: [US-P-01](../participant.md#us-p-01) / SC-P-01 / BR-P-01-03.
- 준비: 등록 0건 상태와 FIX-01의 B팀·맛집 조건을 각각 준비

## QA-P-05-09

- 검증 방법: 요청 횟수만으로 실패 판정하지 말고 최종 등록·집계와 완료 안내를 대조한다.
