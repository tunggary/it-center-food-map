# 부스 관람자·운영자 QA

[역할·화면·분기](../booth.md) · [공통 실행 규칙·테스트 데이터](../../2-user-story.md) · [결정 필요 사항](../decisions.md)

모든 실행 결과는 초기 상태다. 문서의 기대 결과는 실행 증거가 아니며, 실제 실행 전에는 통과로 바꾸지 않는다. 각 항목의 역할은 연결된 스토리를 따른다. 모든 항목에 공통 실행 기록 양식을 사용한다.

## QA-B-01-01

**부스 전용 구성**

- 연결: [US-B-01](../booth.md#us-b-01) / SC-B-01 / BR-B-01-01.
- 준비: FIX-01; PC Chrome
- 절차: 부스 화면을 열어 지도·랭킹·필터를 확인한다.
- 기대 결과: 휴대폰 등록 화면과 구분된다. 장소 핀, 전체 팀 기준 카테고리별 랭킹, 필터를 표시한다. 관리자 설정 없이 팀·카테고리를 자동 순환시키지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-B-01-02

**카테고리 핀 필터**

- 연결: [US-B-01](../booth.md#us-b-01) / SC-B-01 / BR-B-01-02.
- 준비: FIX-01
- 절차: 카페를 선택한 뒤 맛집을 선택한다.
- 기대 결과: 카페는 L1·L2·L3, 맛집은 L1만 표시된다. 한 장소가 여러 분류에 있어도 같은 필터에서 핀이 중복되지 않는다. 랭킹 패널의 축약·전환 방식은 DEC-03이다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-B-01-03

**산책코스 선택**

- 연결: [US-B-01](../booth.md#us-b-01) / SC-B-01 / BR-B-01-03.
- 준비: 서로 다른 R1·R2가 존재
- 절차: 산책 필터에서 R1 시작점을 선택하고 R2를 선택한다.
- 기대 결과: 시작점 핀을 볼 수 있다. 선택한 코스만 전체 경로를 펼치며 이전 선택 경로는 함께 남지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-B-02-01

**신규·기존 항목 등록 알림**

- 연결: [US-B-02](../booth.md#us-b-02) / SC-B-02 / BR-B-02-01.
- 준비: 부스 화면과 별도 참여자 브라우저
- 절차: 새 장소 등록 후 기존 장소에 다른 참여자가 최애로 등록한다. 코스도 등록한다.
- 기대 결과: 각 등록에 닉네임·팀·장소 또는 코스 이름 알림이 나온다. 새 핀이 없는 기존 항목 등록도 생략하지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-B-02-02

**알림 대기와 실시간 결과 분리**

- 연결: [US-B-02](../booth.md#us-b-02) / SC-B-02 / BR-B-02-02.
- 준비: 부스 화면; 여러 참여자를 구분 가능하게 준비
- 절차: 등록을 순차적으로 빠르게 발생시켜 알림 대기를 만든다.
- 기대 결과: 등록 알림은 발생 순서대로 표시된다. 알림 대기로 지도·랭킹 반영이 5초를 넘지 않는다. 노출 시간·재연결 재생은 DEC-10이다.
- 검증 방법: 등록별 완료 시간과 지도·랭킹 반영 시간, 알림 표시 순서를 별도로 기록한다.
- 실행 결과: **미실행**.

## QA-B-02-03

**편집·삭제와 대기 알림**

- 연결: [US-B-02](../booth.md#us-b-02) / SC-B-02 / BR-B-02-03.
- 준비: 표시 전 대기 알림에 해당하는 등록 존재
- 절차: 해당 등록의 닉네임 변경 또는 등록 삭제를 발생시킨다.
- 기대 결과: 대기 알림의 이름·삭제 반영 정책이 미정이다. 등록 알림 정책을 임의로 수정 알림까지 확장하지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **판정 보류**. [DEC-10](../decisions.md#dec-10) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.

## QA-B-02-04

**부스 재연결과 알림 재생**

- 연결: [US-B-02](../booth.md#us-b-02) / SC-B-02 / BR-B-02-04.
- 준비: 부스 알림 대기 중 연결을 끊고 다른 참여자의 등록 발생
- 절차: 부스 연결을 복구하거나 화면을 새로 연다.
- 기대 결과: 복구 시 지난 알림을 재생할지, 어디부터 재생할지, 노출 시간과 대기 한계는 미정이다. 최신 지도·랭킹 갱신은 별도 공통 QA를 따른다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **판정 보류**. [DEC-10](../decisions.md#dec-10) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.
