# 관리자 QA

[역할·화면·분기](../admin.md) · [공통 실행 규칙·테스트 데이터](../../2-user-story.md) · [결정 필요 사항](../decisions.md)

모든 실행 결과는 초기 상태다. 문서의 기대 결과는 실행 증거가 아니며, 실제 실행 전에는 통과로 바꾸지 않는다. 각 항목의 역할은 연결된 스토리를 따른다. 모든 항목에 공통 실행 기록 양식을 사용한다.

## QA-A-01-01

**팀 추가·이름 변경**

- 연결: [US-A-01](../admin.md#us-a-01) / SC-A-01 / BR-A-01-01.
- 준비: 관리 권한; 기존 A팀 등록 존재
- 절차: 새 팀을 추가한다. A팀 이름을 바꾸고 참여 화면·기존 상세·필터를 확인한다.
- 기대 결과: 새 팀이 신규 참여 선택에 나타난다. 기존 팀 이름 변경으로 팀이 복제되거나 횟수가 변하지 않고 연결된 이름 표시가 갱신된다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-A-01-02

**카테고리 유형별 추가·이름 변경**

- 연결: [US-A-01](../admin.md#us-a-01) / SC-A-01 / BR-A-01-02.
- 준비: 관리 권한; 장소형·경로형 기본 등록 흐름 존재
- 절차: 장소형 명소와 경로형 러닝코스를 추가한다. 기존 카테고리 이름을 바꾼다.
- 기대 결과: 각 유형의 등록 흐름을 재사용한다. 이름 변경은 기존 등록의 소속과 횟수를 유지한다. 신규 카테고리 자체가 별도 입력 기능을 만들지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-A-01-03

**신규 선택 중단**

- 연결: [US-A-01](../admin.md#us-a-01) / SC-A-01 / BR-A-01-03.
- 준비: A팀과 카페에 기존 등록 존재
- 절차: 각 목록의 신규 선택을 중단한 뒤 첫 참여·새 등록·기존 조회를 확인한다.
- 기대 결과: 신규 선택에서 제외되지만 기존 등록·팀·카테고리 필터·랭킹 조회는 유지된다. 기존 A팀 참여자의 추가 등록 가능 여부는 DEC-08이다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-A-01-05

**선택 중단된 팀의 기존 참여**

- 연결: [US-A-01](../admin.md#us-a-01) / SC-A-01 / BR-A-01-05.
- 준비: A팀 소속 참여자가 있고 관리자가 A팀 신규 선택을 중단
- 절차: 기존 A팀 참여자가 다른 장소를 등록한다. 작성 중 중단된 카테고리 제출도 시도한다.
- 기대 결과: 기존 참여자의 추가 등록과 작성 중 선택 무효화 정책을 결정해야 한다. 기존 등록의 조회·집계 유지와 혼동하지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **판정 보류**. [DEC-08](../decisions.md#dec-08) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.

## QA-A-02-01

**팀 정정과 기존 집계**

- 연결: [US-A-02](../admin.md#us-a-02) / SC-A-02 / BR-A-02-01.
- 준비: FIX-01의 U1은 A팀, L1 카페 등록
- 절차: 관리자가 U1을 B팀으로 정정한다. 공개 상세와 조건별 집계를 확인한다.
- 기대 결과: L1 전체=4·카페=3 유지; A팀 카페=1, B팀 카페=2가 된다. U1의 기존 등록 표시도 B팀이다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-A-02-02

- 연결: [US-A-02](../admin.md#us-a-02) / SC-A-02 / BR-A-02-02.
- 준비: R1에 여러 명의 등록 존재

- 실행 결과: **판정 보류**. [DEC-01](../decisions.md#dec-01) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.

## QA-A-02-03

**관리자 접근과 참여자 구분**

- 연결: [US-A-02](../admin.md#us-a-02) / SC-A-02 / BR-A-02-03.
- 준비: 일반 참여자 상태와 관리 권한 상태
- 절차: 일반 참여자에서 관리 행동을 시도하고 권한 있는 관리자가 같은 행동을 수행한다.
- 기대 결과: 관리 기능을 일반 참여자에게 허용하지 않는다. 관리자 인증 진입·실패·세션 만료 경험은 미정이므로 해당 분기의 최종 판정은 보류한다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **판정 보류**. [DEC-09](../decisions.md#dec-09) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.

## QA-A-03-01

**개별 등록 삭제**

- 연결: [US-A-03](../admin.md#us-a-03) / SC-A-03 / BR-A-03-01.
- 준비: FIX-01
- 절차: 관리자가 U1의 L1 등록만 삭제한다.
- 기대 결과: U1 등록과 문구·사진이 공개 내용·집계에서 빠지고 L1의 나머지 3건은 유지된다. 숨김·복구 기능은 없다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.

## QA-A-03-02

**전체 삭제 영향 확인·취소**

- 연결: [US-A-03](../admin.md#us-a-03) / SC-A-03 / BR-A-03-02.
- 준비: FIX-01의 L1은 총 4건
- 절차: L1 전체 삭제를 선택해 대상을 확인한 후 취소한다.
- 기대 결과: 장소 이름과 영향 등록 수 4건을 확인할 수 있다. 취소하면 모든 등록·사진·집계·지도 상태가 유지된다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.

## QA-A-03-03

**장소·코스 전체 삭제 실행**

- 연결: [US-A-03](../admin.md#us-a-03) / SC-A-03 / BR-A-03-03.
- 준비: L1 4건과 R1 2건을 각각 독립 상태로 준비
- 절차: 대상과 영향 개수를 확인하고 전체 삭제를 실행한다.

- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **미실행**.

## QA-A-03-04

**관리 작업 실패·동시 변경**

- 연결: [US-A-03](../admin.md#us-a-03) / SC-A-03 / BR-A-03-04.
- 준비: 삭제 확인 이후 다른 참여자가 새 등록할 수 있는 상태
- 절차: 영향 확인 후 새 등록을 만들거나 삭제 요청 실패를 발생시킨다.
- 기대 결과: 영향 수 재확인, 실패 후 화면 처리, 열린 상세의 삭제 안내는 미정이다. 성공하지 않은 삭제를 완료로 판정하지 않는다.
- 검증 방법: DOM·표시 내용과 관련 응답을 확인한다.
- 실행 결과: **판정 보류**. [DEC-06](../decisions.md#dec-06) 확정 필요. 확정된 부분을 관찰하더라도 항목 전체를 통과 처리하지 않는다.
