# 공통 품질·운영 QA

[역할·화면·분기](../shared.md) · [공통 실행 규칙·테스트 데이터](../../2-user-story.md) · [결정 필요 사항](../decisions.md)

모든 실행 결과는 초기 상태다. 문서의 기대 결과는 실행 증거가 아니며, 실제 실행 전에는 통과로 바꾸지 않는다. 각 항목의 역할은 연결된 스토리를 따른다. 모든 항목에 공통 실행 기록 양식을 사용한다.

## QA-N-01-01

**지원 브라우저 핵심 회귀**

- 연결: [US-N-01](../shared.md#us-n-01) / SC-N-01 / BR-N-01-01.
- 준비: 아이폰 Safari·안드로이드 Chrome·PC Chrome; 실행 버전 기록
- 절차: 각 모바일에서 접속·필터·등록·내 최애 수정을 실행한다. PC에서 부스·관리 기능을 실행한다.
- 기대 결과: 지원 환경에서 각 역할의 핵심 흐름을 사용할 수 있다. PC에서 모바일과 동일한 참여 UX를 필수 요구로 추가하지 않는다.
- 검증 방법: DOM·computed style·콘솔·네트워크를 확인하고 기기·브라우저 버전을 실행 기록에 적는다.
- 실행 결과: **미실행**.

## QA-N-01-02

**100명 조건의 첫 표시 3초**

- 연결: [US-N-01](../shared.md#us-n-01) / SC-N-01 / BR-N-01-02.
- 준비: 100개 동시 접속; DEC-12에 확정된 정상 네트워크
- 절차: 접속 시작부터 지도와 첫 랭킹을 모두 확인·조작할 수 있는 시점까지 측정한다.
- 기대 결과: 동시100명 조건에서cold/warm 각각100회 중95회 이상이3초 이내여야 한다. 주소 접속부터 지도와 랭킹을 모두 조작할 수 있을 때까지 측정하고 최대값도 기록한다. 외부지도 지연을 차감하지 않는다. 데이터·네트워크는 확정된 DEC-12 검증 환경을 따른다.
- 검증 방법: 기기·네트워크·부하·개별 측정값·외부 지도 지연을 함께 기록한다.
- 실행 결과: **미실행**. 2026-10-13 정책 확정으로 기대 결과를 갱신했다. 테스트 실행 기록은 아니다.
