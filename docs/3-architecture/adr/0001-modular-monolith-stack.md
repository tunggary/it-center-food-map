# ADR-0001: 정적 앱과 관리형 무료 백엔드를 분리한다

- **상태**: 승인됨 (2026-10-13 사용자 결정 및 보완 계획 채택; 구현·성능 검증과 별개)
- **날짜**: 2026-10-13
- **드라이버**: D1·D7·D8·C1·C4 ([드라이버](../drivers.md))
- **설계 질문**: Q5 — 월0원·100명·행사 이후 참여를 어떤 구성으로 지원할까?
- **관련**: [구현 스택](../stack.md), [운영](../operations.md)

## 컨텍스트

무료만 사용·기존 자원 없음·행사 집중 후 가끔 참여가 사용자 답변으로 확정됐다. 기존 유료안은 이 제약을 만족하지 않는다. 이후 사용자가 개인 프로젝트로 운영하고 Vercel을 사용하도록 지정했다. 정적 지도 앱은 검색엔진용 서버 렌더링이 핵심이 아니며, 쓰기 정합성은 PostgreSQL에 모을 수 있다.

## 검토한 대안

| 대안 | 얻는 것 | 치르는 것 |
| --- | --- | --- |
| Vite/React + Vercel Hobby + Supabase Free | 사용자 배포처 선택, C4 무료 범위, D7 서버 운영 최소화, PostgreSQL 유지 | Vercel 정적 요청/전송 한도, 별도 출처·Supabase 휴면/용량 제한 |
| Vite/React + Cloudflare Pages + Supabase Free | C4 무료 정적 호스팅 대안, 동일 PostgreSQL 모델 유지 | 사용자가 지정한 Vercel과 다른 배포 서비스 운영 |
| Next.js + 무료 서버리스 호스팅 | 기존 프레임워크 구조 유지 | 현재 정적 앱에 불필요한 서버 런타임·실행량 관리 증가 |
| Cloudflare Workers/D1 중심 | 단일 공급자·가벼운 SQL | 기존 PostgreSQL 모델·인증·사진 검증을 더 크게 재설계; worker CPU 제한 |

## 결정

React/Vite 정적 앱을 사용자의 개인 프로젝트로 Vercel Hobby에 배포하고, Supabase Free의 PostgreSQL·Edge Functions·Storage·관리자 Auth를 사용한다. Edge는 서버 검증, SQL RPC는 트랜잭션, Data API 공개 read RPC는 조회를 담당한다. 초기 구현에 Next.js/Drizzle/pg/상시 서버를 넣지 않는다. SQL migration으로 DB 함수를 관리한다.

## 근거

C4를 지키면서 관계형 원장과 R1~R6를 보존할 수 있다. 요청마다 Edge를 거치지 않는 공개 읽기와 정적 호스팅으로 제한 자원을 아낀다. 사용자가 개인 프로젝트와 Vercel을 명시했으므로 앞선 용도 불확실성에 따른 제외 결정을 철회한다. 무료 한도 안에서 가능한 구성이며 무기한 무제한 가용성 보장은 아니다.

## 결과

- **좋아진 것**: 유료 고정비 없음, FE/API/DB 책임 명확, 같은 DB에 업무 규칙 집약.
- **감수할 것**: 별도 출처 자격 전달, SQL 함수 테스트/배포 필요, 휴면과 수동 백업 운영. 휴면 수동 재개와 수동 백업의 손실 범위를 사용자가 수용했다.
- **함정**: 무료 API 횟수를 성능/egress 무제한으로 해석하거나 Vercel 정적 요청도 무제한으로 오인, 정적 배포에 서버 API가 포함된다고 가정, preview에 운영 DB 연결, DB백업을 사진백업으로 오인.
- **새로 생긴 설계 숙제**: Q2 자격 전달→ADR-0003, Q4 호출/전송량→ADR-0005, Q6 이미지 런타임→ADR-0006. 운영 기본값은 연결 문서에 명시.

## 검증

G1 무료 실행 경계·G2 WASM·G4 100명 성능과 egress를 실제 측정한다. DB/사진 복원 연습을 하고 무료 제한 초과를 자동결제로 해결하지 않는다.

## 재검토 트리거

항상 즉시 접속이 필수라 휴면 수동 재개를 수용할 수 없음, 실제 한도/지연 시험 실패, 사진량이 무료 예산 초과, 외부 무료 정책 변경. 이를 발견하면 구조를 재검토하고 요구를 조용히 낮추지 않는다.

## 변경 이력

- 최초안: Next.js/Vercel Pro/Supabase Pro, 소액 유료 가정으로 제안됨.
- 2026-10-13: 사용자 무료 조건으로 같은 제안 ADR 개정. 비용 제약은 합의, 상세 운영/성능은 검증 전. 기존 승인 ADR 대체 없음.

- 2026-10-13: 사용자가 개인 프로젝트로 Vercel을 쓰도록 지정했다. Cloudflare Pages 제안을 Vercel Hobby 정적 배포로 변경하고 기본 도메인·SPA rewrite·CORS·CDN 요청/전송 예산을 갱신했다. Supabase API/DB/사진 처리 경계는 유지했다.

- 2026-10-13: 사용자가 남은 제품·운영 정책과 상세 보완 계획을 채택해 승인됨으로 전환했다. 이는 구현/성능 통과가 아니다. 용량 예약·백업 실행/복원 계약은 [용량](../storage-accounting.md)·[백업](../backup.md)에 연결했다.
